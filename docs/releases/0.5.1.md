# Collegare 0.5.1 (Vorabversion zum Testen)

- **Material zum Einarbeiten.** Neue Kachel „Material“ und Eintrag im Seitenmenü, für Lernende von Anfang an sichtbar,
  auch beim Start aus Moodle (LTI). Lehrkräfte veröffentlichen dort:
  - **Lernseiten im Tufte-Stil:** direkt in Collegare geschrieben, mit nummerierten Randnotizen (`^[…]`),
    Marginalien (`^^[…]`), Zitaten, Bildern mit Unterschrift am Rand und eingebetteten Videos. Schreiben mit
    Werkzeugleiste und Vorschau daneben. Auf dem Smartphone rücken die Randnotizen als eingerückter Kasten direkt
    hinter den Satz in den Text.
  - **Word übernehmen:** eine DOCX-Datei wird im Browser zur Lernseite (Überschriften, Listen, Fett/Kursiv, Bilder
    verkleinert, Fußnoten als Randnotizen).
  - **Webseiten** als Link, **Videos** von YouTube (ohne Cookies) oder Vimeo eingebettet oder als Datei,
    **PDF und Dokumente** als Notlösung (PDF im Browser, sonst Download). Reihenfolge, Titel und Hinweis änderbar.
- Kopfzeile wird auf schmalen Bildschirmen nicht mehr breiter als das Gerät.

Aktualisieren: `collegare aktualisieren`.
