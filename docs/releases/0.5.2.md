# Collegare 0.5.2 (Vorabversion zum Testen)

- **Worterklärungen auf Lernseiten.** `{Wort|Erklärung}` (oder Knopf „Worterklärung“) macht ein Wort halbfett.
  Erst ein Klick auf das Wort öffnet die Erklärung, am Rand oder auf dem Smartphone direkt unter dem Satz;
  ein zweiter Klick schließt sie wieder. So stört sie den Lesefluss nicht.
- Randnotizen (`^[…]`) und Marginalien (`^^[…]`) bleiben wie bisher immer sichtbar.

Aktualisieren: `collegare aktualisieren`.
