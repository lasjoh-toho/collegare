# Collegare 0.7.23

## Bild aufnehmen mit Texterkennung

- **Bild aufnehmen:** Im Notiz-Editor von „Notizen und Quellen“ öffnet „Bild aufnehmen“ den Dokumentenscanner aus
  Autogra.fi: Kamera (am Handy sofort), Eckenerkennung, Entzerren, Unschärfe-Warnung, Ränder abschneiden, auch ein Bild
  aus der Galerie. Das Bild bleibt in seinen Farben und wird eine Notiz der Art „Handschrift“ (in einer Bildquelle
  bleibt es eine Bildquelle). Der bisherige Knopf „Foto“ entfällt.
- **Text erkennen:** Bei Handschrift- und Bildnotizen liest die KI den Text auf dem Bild. Erst dafür wird eine Kopie
  aufbereitet (Graustufen, Kontrast, verkleinert); gespeichert wird nur das Originalbild. Danach stehen Bild und Text
  nebeneinander zum Vergleichen und Verbessern, „Erkannten Text wiederherstellen“ holt den erkannten Stand zurück.
  Der erkannte Text erscheint im Einfüge-Protokoll als „Handschrift“, nicht als Einfügen von außen.
- **KI-Konfiguration** (Verwaltung): Modellkarten wie in Autogra.fi für Ollama im Schulnetz, OpenAI-kompatible Dienste
  und Gemini, mit „Prüfen“, Reihenfolge und Export/Import. Die Datei aus Autogra.fi („Exportieren“ in der
  KI-Konfiguration) lässt sich direkt importieren; die Karte mit der Verwendung „Texterkennung“ übernimmt sie hier.
  API-Schlüssel bleiben auf dem Server und stehen nicht in der Datei.
- **Schalter:** Rahmen für Projekte → „Texterkennung erlauben“, Projekt-Einstellungen → „Text in aufgenommenen Bildern
  erkennen (KI)“. Beides ist an; ohne Modellkarte zeigt der Knopf den Grund.
