# Collegare 0.7.34

## Arbeitsblätter und Klassenarbeiten

- **Pinsel für Bilder** (Reiter „Bild“ → Bearbeiten): Aufhellen (Abwedeln), Abdunkeln (Nachbelichten) und Verpixeln
  (z. B. Gesichter oder Namen unkenntlich machen). Größe, Stärke bzw. Pixelgröße sind einstellbar. „Zurück“ (Strg+Z)
  nimmt den letzten Strich zurück, Enter übernimmt, Esc bricht ab. „Original“ stellt das Bild wieder her.
