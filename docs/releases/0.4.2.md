# Collegare 0.4.2 (Vorabversion zum Testen)

- **Mindmap: erst Ideen, dann Abschnitte.** In der Ansicht „Äste“ legt `+ Idee` (oder Tab, oder das + am Thema)
  eine lockere Idee an: dünner grauer Ast, Text ohne Form. So lässt sich schnell sammeln. Zeigen sich Themen,
  macht „Als Abschnitt“ eine Idee zum farbigen Hauptast; andere Ideen hängt ihr mit „Hängen an …“ daran oder löst
  sie wieder. Nur Hauptäste werden Abschnitte der Gliederung.
- Leer gelassene neue Ideen verschwinden wieder.
