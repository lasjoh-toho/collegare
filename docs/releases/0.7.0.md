# Collegare 0.7.0 (Vorabversion zum Testen)

- **Folien mit Bento statt OnlyOffice:** Die Präsentation der Gruppe öffnet jetzt in Bento, mit einem Menüband
  wie in PowerPoint (Datei, Start, Einfügen, Entwurf, Übergänge, Animationen, Bildschirmpräsentation, Überprüfen,
  Ansicht). Dazu kommen aus Bento **Format übertragen**, **Schrift einbetten**, die **Medienübersicht**, Morph,
  Diagramme aus Tabellen und die Referentenansicht. Texte und Tabellen bleiben in OnlyOffice.
- **Import und Export** unter „Datei“: PowerPoint (.pptx, .ppt beim Import), Bento-HTML und JSON. Lernende
  können erst importieren, wenn „Lernende dürfen Präsentationen importieren“ in den Einstellungen an ist.
- Gespeichert wird automatisch auf dem Server. Lehrkräfte sehen die Präsentation einer Gruppe nur zum Ansehen
  und Vorführen, außer im eigenen Testbereich.
- Noch nicht: gleichzeitiges Bearbeiten mehrerer Personen. Beim PowerPoint-Export gehen Formeln als Text, Videos
  als Platzhalter und Diagramme als Bild.

Aktualisieren: `collegare aktualisieren`. Beim Bauen eines Release wird Bento mit npm gebaut.
