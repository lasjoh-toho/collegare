# Collegare 0.5.3 (Vorabversion zum Testen)

- **Worterklärungen für Touch-Geräte.** Größere Tippfläche um das Wort, kein Doppeltipp-Zoom und kein grauer
  Tipp-Blitz. Die gepunktete Unterstreichung gibt es nur noch mit Maus, damit sie nach dem Antippen nicht hängen
  bleibt. Das geöffnete Wort ist leicht hinterlegt. Ein Tipp auf die Erklärung selbst schließt sie wieder.
  Geprüft mit iPhone-, Android- und iPad-Emulation.

Aktualisieren: `collegare aktualisieren`.
