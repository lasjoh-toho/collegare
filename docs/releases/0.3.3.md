# Collegare 0.3.3 (Vorabversion zum Testen)

- **Projekt-Portal wie in Autogra.fi:** Lehrkräfte und Administration landen nach der Anmeldung auf einem Portal
  mit Seitenleiste (Administration, Meine Projekte, Klassen). „Bestehende Projekte“ als Karten oder Tabelle mit
  Phase, Gruppenstand und fertigen Abschnitten, dazu „Neu seit dem letzten Besuch“.
- **Verwaltung** (Lehrende, Rahmen für Projekte, Moodle-Verbindung) in derselben Seitenleiste; „Lehrende“ zeigt
  zuerst die Tabelle, darunter „Neue Lehrkraft anlegen“.
- **Terminal:** `collegare passwort` und `collegare admin` fragen das Passwort verdeckt und zweimal ab.

Aktualisieren: `collegare aktualisieren`. Die Datenbank ändert sich nicht.
