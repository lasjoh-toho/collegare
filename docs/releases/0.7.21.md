# Collegare 0.7.21

## Arbeitsblätter und Klassenarbeiten: Reiter „Datei“

- **Datei** steht vorn im Menüband: speichern, Kopie anlegen (z. B. für Gruppe B oder eine Nachschrift), drucken oder
  als PDF speichern.
- **Exportieren** als Word-Datei zum Weiterbearbeiten (mit Fußnoten, Punkten, Schreiblinien, Tabellen, Bildern und
  Diagrammen), als Webseite (alle Seiten in einer HTML-Datei) oder als reiner Text.
- **Blatt-Datei:** das ganze Blatt samt Bildern als Datei an Kolleginnen und Kollegen weitergeben und dort öffnen.

Konzept: `docs/konzept.md`, Abschnitt 8j.9.
