# Collegare 0.2.0 (Vorabversion zum Testen)

Ergänzt 0.1.0 um den Ablauf vom Ideensammeln bis zum Schreiben.

- **Verwaltung:** Lehrkräfte anlegen, Passwort setzen, „Ansehen als“ mit Rückweg; Seite „Rahmen für Projekte“
  (erlaubte Dokument- und Dateitypen, KI, Tippfluss-Hinweise, offenes Office)
- **Orientierung:** Mindmap je Gruppe in Echtzeit mit Karten, Clustern, Pfeilen und Zuständigen;
  „Gliederung übernehmen“ macht aus jedem Cluster einen Abschnitt
- **Ausarbeitung:** je Karte der Gliederung ein Textdokument im Office-Editor, gemeinsam bearbeitbar und dauerhaft
  gespeichert; „Fertig melden“ sperrt das Dokument, „Wieder öffnen“ je nach Projekteinstellung
- Das offene Office unter `/collegare/office/` ist ohne Anmeldung nur erreichbar, wenn der Rahmen es erlaubt

Bekannt: Die leere Textvorlage nutzt noch eine chinesische Standardschrift (Issue #9).

Aktualisieren: neues Paket entpacken und `sudo ./install.sh` aufrufen; die Datenbank wird beim Start ergänzt.
