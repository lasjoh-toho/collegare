# Collegare 0.1.0 (Vorabversion zum Testen)

Erste installierbare Fassung für den Test mit Moodle 4.4.

- Anmeldung für Lehrkräfte, Zugangscodes und QR-Zettel für Lernende
- Projekte mit Gruppen-Kanban (Lehrkraft teilt ein, Wahl oder offene Bildung) in Echtzeit
- Projekt-Einstellungen mit Voreinstellungen (Referat, Seminar, Facharbeit, Prüfung)
- Moodle über LTI 1.3: Start aus der Aktivität, Teilnehmende übernehmen (NRPS)
- Office-Editoren (Text, Tabelle, Präsentation) unter `/collegare/office/`, noch ohne Speichern im Projekt

Installation: [docs/installation.md](../installation.md). Die Datenbank wird beim ersten Start angelegt.
