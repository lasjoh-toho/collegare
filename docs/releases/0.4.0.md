# Collegare 0.4.0 (Vorabversion zum Testen)

- **Collegare als Kontodienst (Konzept 8c):** Neue Verwaltungsseite „Angebundene Apps“. Dort trägt die
  Administration Apps wie Autogra.fi ein. Diese melden Lehrkräfte dann mit ihrem Collegare-Konto an
  (OpenID Connect mit PKCE). Anbieter-Adresse ist die Adresse von Collegare, z. B. `https://server/collegare`.
- **Office ohne Anmeldung auf der Startseite:** Ist im „Rahmen für Projekte“ das Office ohne Anmeldung erlaubt,
  zeigt die Startseite Text, Präsentation, Tabelle und „Datei öffnen“.
- **Lehrende:** Spalte „Projekte“ und Löschen (nur ohne laufende Projekte, nie das eigene Konto).

Aktualisieren: `collegare aktualisieren`.
