# Collegare 0.4.1 (Vorabversion zum Testen)

- **Mindmap als Äste:** Neben der Karten-Fläche gibt es jetzt eine klassische Mindmap. Das Thema steht in der
  Mitte, farbige Äste werden nach außen dünner, und der Text steht am Ast. Knoten können eine Form bekommen
  (Rechteck, Oval, Raute, Parallelogramm). Jeder Hauptast wird ein Abschnitt der Gliederung, Unteräste mit
  zuständiger Person werden zu Textabschnitten. Tastatur: Tab legt einen Unterast an, Enter benennt um.
  Umschalter „Äste / Karten“ oben rechts; beide Ansichten zeigen dieselbe Mindmap.

Aktualisieren: `collegare aktualisieren`.
