# Collegare 0.6.1 (Vorabversion zum Testen)

- **Pinnwand aus der Mindmap** (Konzept 8d.5): Auf der Pinnwand gibt es oben den Knopf „Aus der Mindmap“.
  - Was in der Mindmap „In die Gliederung“ übernommen ist, kommt auf die Pinnwand: Jeder Ast wird ein Rahmen im
    Roten Faden (in der Reihenfolge der Gliederung), jede Karte ein Zettel (Wortfeld) in diesem Rahmen.
  - Erneut drücken ergänzt nur, was noch fehlt; Verschobenes und Bearbeitetes bleibt, wie es ist.
  - Ist noch nichts übernommen, sagt die Pinnwand das, statt ein leeres Board anzulegen.
