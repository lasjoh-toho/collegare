# Collegare 0.4.6 (Vorabversion zum Testen)

- **Eigene Kurse für alle Lehrenden:** Wer schon irgendwo Lehrkraft oder Administration ist (auch nur über einen
  Moodle-Kurs), bekommt beim ersten „Neuer Kurs …“ automatisch einen eigenen Bereich. Die Meldung „Nur für
  Lehrkräfte mit eigenem Bereich“ entfällt; Lernende können weiterhin keine Kurse anlegen.
- `…/collegare/api/public` nennt die laufende Version. So lässt sich prüfen, ob eine Aktualisierung angekommen ist.

Aktualisieren: `collegare aktualisieren`.
