# Collegare 0.3.1 (Vorabversion zum Testen)

- **Installieren und Aktualisieren im Terminal:** ein Befehl lädt die neueste Version, prüft die Prüfsumme und richtet
  alles ein. Danach gibt es auf dem Server den Befehl `collegare` (`aktualisieren`, `version`, `zurueck`, `status`,
  `protokoll`, `admin`, `passwort`). Anleitung: `docs/installation.md`.
- Läuft auch ohne `sudo` (z. B. TurnKey LAMP als root); die Adresse schlägt der Installer selbst vor
- **Notizen und Quellen** sind eine gemeinsame Kachel in der Phase Recherche statt zwei getrennter.

Erstinstallation (als root ohne `sudo`, `--url` ist optional):

```bash
curl -fsSL https://raw.githubusercontent.com/lasjoh-toho/collegare/main/packaging/collegare.sh \
  | sudo bash -s -- installieren --url https://server.schule.de/collegare --admin <kürzel>
```

Aktualisieren von 0.3.0 oder älter (einmalig, danach `sudo collegare aktualisieren`):

```bash
curl -fsSL https://raw.githubusercontent.com/lasjoh-toho/collegare/main/packaging/collegare.sh | sudo bash -s -- aktualisieren
```

Die Datenbank ändert sich nicht; zurück auf 0.3.0 geht mit `sudo collegare zurueck 0.3.0`.
